Part 2 — jQuery Effects

Tasks 2 to 4: visibility, fade and slide methods.

Task 2

Visibility methods

A paragraph controlled by Hide and Show buttons, plus a toggle button.

This paragraph is hidden and shown with .hide(), .show() and .toggle(). Press the buttons and watch the layout collapse and come back. 

// Task 2
$("#btn-hide").on("click", function () { $("#visibility-text").hide(400); });
$("#btn-show").on("click", function () { $("#visibility-text").show(400); });
$("#btn-toggle-vis").on("click", function () { $("#visibility-text").toggle(400); });
Task 3

Fade methods

An image that fades in, fades out and toggles its opacity.

// Task 3
$("#btn-fade-in").on("click", function () { $("#fade-image").fadeIn(600); });
$("#btn-fade-out").on("click", function () { $("#fade-image").fadeOut(600); });
$("#btn-fade-toggle").on("click", function () { $("#fade-image").fadeToggle(600); });
Task 4

Slide methods

A collapsible panel controlled with the slide methods.

Why is jQuery still useful today?

jQuery wraps complex browser APIs into short, chainable methods. A single line such as $("#panel").slideToggle() replaces a lot of manual DOM, style and animation bookkeeping — which is why it is still found in many legacy and CMS-based projects. 

// Task 4
$("#btn-slide-up").on("click", function () { $("#slide-panel").slideUp(500); });
$("#btn-slide-down").on("click", function () { $("#slide-panel").slideDown(500); });
$("#btn-slide-toggle").on("click", function () { $("#slide-panel").slideToggle(500); });
