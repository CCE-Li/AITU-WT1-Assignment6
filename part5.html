Task 11

Accordion Menu

Click a section header to open it. The open section slides closed automatically, so only one panel is visible at a time — the classic accordion behaviour built from .slideUp() and .slideDown().

jQuery is a fast, small and feature-rich JavaScript library. It makes HTML document traversal and manipulation, event handling and animation much simpler through an easy-to-use API that works across many browsers.

Selectors find the elements you want to work with: $("#id") for an ID, $(".class") for a class and $("p") for a tag. The same selector can match many elements, and the resulting collection supports chaining.

Visibility: .hide(), .show(), .toggle(). Fading: .fadeIn(), .fadeOut(), .fadeToggle(). Sliding: .slideUp(), .slideDown(), .slideToggle().

The .animate() method changes any numeric CSS property — size, position, opacity — over a given duration. Chained calls are queued and executed one after another, which makes step-by-step animations easy to build. 

// Task 11 — accordion menu
$(".accordion__header").on("click", function () {
  var $item = $(this).parent();

  if ($item.hasClass("is-open")) {          // already open -> close it
    $item.removeClass("is-open");
    $item.find(".accordion__content").slideUp(400);
    return;
  }

  $(".accordion__item").removeClass("is-open");            // close the others
  $(".accordion__content").slideUp(400);

  $item.addClass("is-open");                                // open the clicked one
  $item.find(".accordion__content").slideDown(400);
});
