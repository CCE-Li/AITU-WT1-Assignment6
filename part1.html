Setup

jQuery is loaded from the official CDN, a $(document).ready() function runs on every page, and it prints "jQuery is ready!" in the console.

  • jQuery included from a CDN — currently reporting version checking…
  • $(document).ready() handler registered in js/common.js
  • "jQuery is ready!" written to the browser console when the DOM is ready
// js/common.js
$(document).ready(function () {
  console.log("jQuery is ready!");
  console.log("jQuery version:", $.fn.jquery);
});
