Part 4 — Animations

Tasks 8 to 10: basic, sequential and combined .animate() calls.

Task 8

Basic animation

The square grows and moves to a new position with a single .animate() call.

Task 8
// Task 8
$("#btn-animate-basic").on("click", function () {
  $("#box8").animate({
    width: "180px",
    height: "180px",
    left: "420px",
    top: "60px"
  }, 900);
});
Task 9

Sequential animations

The box is animated step by step: move right → move down → shrink → return to the original position. Chained .animate() calls run one after another.

Task 9
// Task 9 — the queue runs these one after another
$("#box9")
  .animate({ left: "560px" }, 600)                 // 1. move right
  .animate({ top: "120px" }, 600)                  // 2. move down
  .animate({ width: "50px", height: "50px" }, 600) // 3. shrink
  .animate({ left: "20px", top: "20px", width: "90px", height: "90px" }, 700); // 4. return
Task 10

Combined animation

Opacity, size and movement change together inside one .animate() call.

Task 10
// Task 10 — opacity + size + movement in ONE call
$("#box10").animate({
  opacity: 0.25,
  width: "200px",
  height: "200px",
  left: "480px",
  top: "40px"
}, 1000);
